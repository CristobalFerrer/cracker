        What is the "PCI-style" column?
        

          Regions come from thresholded crack probability (8-connected components). The PCI-style column is a
          shape heuristic only (elongation + orientation in image coordinates). It is not an
          ASTM D6433 survey, official severity, or certified PCI index. Align your ortho so lane / longitudinal cracks run
          roughly horizontally if you want “longitudinal-like” to match pavement axes.
        

      

      

        
        Viewer uses a downscaled copy; lengths/areas convert using full-res pixel size.
